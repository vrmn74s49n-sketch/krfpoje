# KRF Proje — statik web sitesi

Bu site GitHub Pages ile ücretsiz yayınlanmak üzere hazırlanmıştır.

## Dosyalar
- index.html
- styles.css
- script.js
- CNAME

## Domain
CNAME dosyasında `krfproje.com` bulunur.

## GitHub Pages
1. GitHub'da public bir repository oluşturun.
2. Bu dosyaları yükleyin.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)` seçin.
4. Settings → Pages → Custom domain kısmına `krfproje.com` yazın.
5. TürkTicaret DNS panelinde GitHub'ın verdiği kayıtları tanımlayın.

Not: DNS değişiklikleri yayılana kadar beklemek gerekebilir.
